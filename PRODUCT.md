# Product

## Register

Product

## Users

People using Codex locally who want a fast, private view of token usage, cache performance, and project activity without uploading their usage data.

## Product Purpose

Token Ledger turns local Codex usage metadata into a readable terminal dashboard and polished PNG reports. It should make the common questions easy to answer: how much was used, where it went, how the weekly meter changed, and how effectively input tokens were cached.

## Brand Personality

Precise, calm, concise, and trustworthy.

## Anti-references

- Bloated command help that presents every implementation detail at once.
- Repeated explanations that hide the next useful action.
- Setup jargon in primary workflows.
- Ambiguous labels or examples that imply behavior the command does not provide.

## Design Principles

- Lead with the next useful action.
- Keep common workflows obvious and memorable.
- Use progressive disclosure for advanced, diagnostic, and legacy controls.
- Preserve predictable terminal conventions and copyable examples.
- Protect local data and clearly state the privacy boundary.
- Make errors brief, specific, and actionable.

## Accessibility and Inclusion

- Every workflow must remain understandable without color.
- Plain and ASCII output modes must remain available.
- Help and errors should stay readable at ordinary terminal widths.
- Never use color as the only way to communicate meaning.
- Use direct language and examples that do not assume deep CLI knowledge.
